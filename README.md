## Инструкция запуска

1. Как запустить приложение?
   Приложение запускается через docker-compose командой docker-compose up -d. Состав сборки: nginx для фронта, основное fastapi приложение, postgre для хранения данных, redis для публикации событий, отдельный redis_worker отправки уведомлений и mailhog как приемщик писем.
2. Как зарегестрироваться?
   Зайти на страницу регистрации в веб-приложении; ввести почту и пароль;
3. Как получить ключ?
   Первый ключ появлется автоматически у пользователя при регистрации. В любой момент можно обновить ключ в личном кабинете. Сам ключ можно узнать только в письме который отправляется на указанную почту.
4. Как запустить десктопное приложение?
   Скачать и запустить exe который находится в директории desktop/release
